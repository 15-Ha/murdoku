# Mordoku

Einzelne HTML-Datei (`index.html`) – ohne Installation im Browser lauffähig, auch auf Smartphone und Tablet.

Krimi-Logikrätsel nach dem Prinzip der Murdoku-Rätsel: Personen auf einen Plan stellen (eine pro Zeile und Spalte), Aussagen auswerten, Täterin oder Täter überführen.

- Ablauf: zuerst Grösse (4×4 bis 7×7) und Niveau (Sehr leicht bis Ultraschwer) wählen, dann das Rätsel erstellen. Alle Rätsel sind eindeutig und rein logisch lösbar.
- Verdächtige als Karten mit Porträt und Aussagen, eigene Spielanleitung beim ersten Start.
- Werkzeuge: Kreuz-Modus, Auto-Kreuze, Radierer, Rückgängig, Notizen, Tipps (je nach Niveau begrenzt).
- Geprüft wird erst beim Abgeben. Arbeitsblatt-Export über «Drucken» (PDF).

Teil der Logiklandschaft (Repository `logiklandschaft`).
